# ゲームシナリオレビュー

シナリオの論理的整合性・構造的健全性・品質を多角的に検証する。
検出した問題は重要度付きの課題一覧表として出力する。

---

## 1. フラグ整合性チェック

### 検出対象

- **未知情報の漏洩**：プレイヤーがまだ知らないはずの情報をキャラクターが語る
- **未設定フラグの参照**：設定されていないフラグを条件に使用している
- **設定済みフラグの未参照**：設定されたが一度も参照されないフラグ（不要フラグ）
- **フラグ値の矛盾**：同一フラグが異なるパスで矛盾する値を持つ可能性

### 検証手順

1. 全フラグの設定箇所と参照箇所を一覧化する
2. 各参照箇所について、その時点で設定済みであることを全経路で確認する
3. 依存関係グラフを構築し、循環依存がないか検証する
4. 情報フラグ（キャラが知っている事実）と台詞の整合性を照合する

---

## 2. 分岐到達可能性の検証

### 検出対象

- **デッドエンド**：進行不能になるノード（意図的なバッドエンドを除く）
- **到達不能ノード**：どの経路からもたどり着けないシーンやエンディング
- **孤立ノード**：入口はあるが出口がないノード（進行停止）
- **意図しないショートカット**：設計外の経路で重要シーンを飛ばせる

### 検証手順

1. 分岐図を有向グラフとして構築する
2. 開始ノードから全ノードへの到達可能性を検証する
3. 全エンディングノードへの経路が存在することを確認する
4. 各ノードから少なくとも1つのエンディングへ到達可能か確認する

---

## 3. キャラクター整合性チェック

### 検出対象

- **口調の不一致**：設定された口調パターンからの逸脱
- **動機の矛盾**：キャラクターの行動が設定された欲求・葛藤と矛盾する
- **関係性の矛盾**：ルート間でキャラクター間の関係が設定と食い違う
- **知識の不整合**：キャラクターの知識状態が場面間で矛盾する
- **成長弧の断絶**：キャラクターの成長が不自然に飛躍・退行する

### 検証手順

1. キャラクターシートと実際の台詞・行動を照合する
2. 各ルートでのキャラクターの知識状態を追跡する
3. 感情変化の流れに不自然な飛躍がないか確認する
4. 複数ライターが担当する場合、口調設定表との一致を検証する

## 4. 伏線管理（Plant → Payoff マッピング）

### 管理表の構成

| 伏線ID | 配置箇所 | 配置内容 | 回収箇所 | 回収内容 | 状態 |
|--------|---------|---------|---------|---------|------|
| F001 | Ch1-Sc05 | 壁の傷跡の描写 | Ch4-Sc12 | 傷跡が事件の鍵と判明 | 回収済み |
| F002 | Ch2-Sc03 | NPCの不自然な発言 | 未定 | - | **未回収** |

### 検出対象

- **未回収の伏線**：配置されたが回収されていない伏線
- **回収のない配置**：意味ありげな描写だが回収計画がない
- **早すぎる回収**：配置直後に回収され、伏線として機能していない
- **ルート横断型伏線の漏れ**：特定ルートでのみ意味を持つ伏線が、他ルートで矛盾を生む

### ルート横断型伏線の特別検証

強制ルート順序がある作品では、前ルートで気にならなかった描写が次ルートで意味を持つ設計を検証する。各ルートの伏線が他ルートのネタバレにならないことを確認する。

## 5. テキスト量バランス分析

### 検証項目

- **ルート間のテキスト量差**：極端な差がないか（目安：最短ルートが最長の50%未満は要検討）
- **共通ルートと個別ルートの比率**：共通パートが長すぎると2周目以降の体験が悪化
- **日常パートと本筋の比率**：日常パートが感情的投資として機能しているか
- **選択肢の分布**：序盤に選択肢が集中/欠如していないか

### 出力指標

| 指標 | 値 | 目安 |
|------|-----|------|
| 共通ルート文字数 | - | 全体の20-40% |
| 各ルート文字数 | - | ルート間差は1.5倍以内 |
| 選択肢総数 | - | プロジェクト依存 |
| バッドエンド数 | - | プロジェクト依存 |

## 6. 出力：課題一覧表

検出した全問題を以下のフォーマットで出力する。

| # | カテゴリ | 問題内容 | 該当箇所 | 重要度 | 修正提案 |
|---|---------|---------|---------|--------|---------|
| 1 | フラグ矛盾 | flag_x が未設定の状態で参照 | Ch3-Sc08 | **致命的** | Ch2 で flag_x を設定する分岐を追加 |
| 2 | デッドエンド | 選択肢Bで進行不能 | Ch4-Sc15 | **致命的** | 遷移先ノードを追加 |
| 3 | 口調不一致 | キャラAが敬語を使用（設定はタメ口） | Ch2-Sc12, L45 | 中 | 口調設定に合わせて台詞を修正 |
| 4 | 伏線未回収 | F002: NPCの不自然な発言 | Ch2-Sc03 | 中 | 回収シーンを追加、または描写を削除 |
| 5 | テキスト量 | ルートBが最短ルートの40% | ルートB全体 | 低 | シーン追加またはルート統合を検討 |

### 重要度の定義

| 重要度 | 基準 |
|--------|------|
| **致命的** | 進行不能・論理破綻・フラグ矛盾（リリース前に必ず修正） |
| **高** | 体験を著しく損なう（プレイヤーの没入感が破壊される） |
| **中** | 品質低下だが進行に影響なし（修正推奨） |
| **低** | 改善の余地あり（時間があれば対応） |

## 7. 使用方法

このスキルを呼び出す際は、以下の情報を提供してください。

- **レビュー対象**：シナリオ全体 / 特定ルート / 特定チャプター
- **レビュー観点**：全項目 / フラグのみ / 伏線のみ 等
- **シナリオデータ**：台詞スクリプト、分岐図、条件表、キャラクターシート等

### 呼び出し例

```
シナリオレビューをお願いします。
- 対象: チャプター3全体
- 観点: フラグ整合性と伏線管理
- データ: [シナリオファイルと条件表を添付]
```
