# SEOコンテンツ最適化スキル

検索意図の分析からコンテンツ構造の設計、メタ情報の最適化まで、
オンページSEOの改善を体系的に実施するワークフローです。
AI Overview時代に対応した最適化手法を含みます。

## 前提条件

- 対象ページのURLまたはコンテンツが指定されていること
- ターゲットキーワードが明確であること（未定の場合はキーワード分析から開始）

## 最適化ワークフロー

### ステップ1: 検索意図の分析

ターゲットキーワードの検索意図を4タイプに分類する:

| 意図タイプ | 説明 | コンテンツ方針 |
|-----------|------|-------------|
| 情報型（Informational） | 知識・方法を求める | 包括的ガイド、How-to、FAQ |
| 案内型（Navigational） | 特定サイト/ページを求める | ブランドページ、製品ページ |
| 取引型（Transactional） | 購入・申込を意図 | LP、製品比較、レビュー |
| 商業調査型（Commercial） | 購入前の比較検討 | 比較記事、ランキング、事例 |

- 検索結果上位10件のコンテンツタイプを確認し、意図との整合性を判断する
- AI Overviewが表示されるクエリかどうかを確認する
- ロングテールキーワードの関連候補もリストアップする

### ステップ2: タイトルタグの最適化

**基準値:**
- 日本語: 32文字以内
- 主要キーワードを冒頭付近に配置
- 各ページで固有のタイトルを設定
- Googleは約61%のタイトルを書き換えるため、H1も短く明確にする

**チェック項目:**
- キーワードの詰め込みがないか（不自然な反復は厳禁）
- クリックを誘引する要素があるか（数字、具体性、独自性）
- 競合との差別化ポイントが含まれているか

### ステップ3: メタディスクリプションの最適化

**基準値:**
- 日本語: 100〜120文字程度（途切れず表示される範囲）
- 冒頭50文字以内に最重要内容とキーワードを含める
- 直接的なランキング要因ではないが、CTRに大きく影響

**チェック項目:**
- 検索クエリと一致するキーワードが含まれているか（太字表示される）
- 行動喚起（CTA）要素があるか
- ページの内容を正確に要約しているか

### ステップ4: 見出し構造（H1〜H6）の設計

**ルール:**
- H1は1ページに1つのみ、主要キーワードを含む（60〜80文字以内）
- H2は主要セクション区切り（1,000語あたり5〜10個目安）
- H3はH2配下のサブセクション（H2が300語超の場合に分割検討）
- 見出しレベルの飛ばし禁止（H1→H3は不可、必ずH2を経由）
- フィーチャードスニペット獲得を意識した構造にする

**設計テンプレート:**
```
H1: [主題] -- 主要キーワードを含む
  H2: [セクション1] -- 検索意図に最も直結する内容
    H3: [詳細1-1]
    H3: [詳細1-2]
  H2: [セクション2] -- 補足・深掘り
    H3: [詳細2-1]
  H2: [セクション3] -- 実践・応用
  H2: [まとめ/FAQ] -- AI Overview抽出を意識
```

### ステップ5: 本文コンテンツの最適化

**E-E-A-T強化ポイント:**
- Experience（経験）: 実体験、独自データ、一次情報を含める（AI最大の差別化要素）
- Expertise（専門性）: 著者の経歴・資格を明示
- Authoritativeness（権威性）: 信頼できるソースからの引用・言及
- Trustworthiness（信頼性）: 透明性の高い情報開示

**キーワード配置の自然な位置:**
- 本文の最初の100語以内
- H2/H3見出し内
- 画像alt属性
- URL

**AI Overview対応（FactLock技法）:**
- 検証可能な具体的データポイントを含める（割合、日付、固有名詞）
- 40〜60語の簡潔な回答段落をQ&A形式で用意
- AIが要約できない一次情報・独自データを提供

### ステップ6: 画像最適化

| 項目 | 基準値 |
|------|-------|
| フォーマット | WebP推奨（AVIF はpicture タグでプログレッシブ提供） |
| ファイルサイズ | 200KB以下 |
| alt属性 | 125文字以下、具体的に記述（「画像の〜」接頭辞不要） |
| ファイル名 | ハイフン区切りの記述的名称 |
| width/height | 必ず明示（CLS防止） |
| lazy loading | below-the-fold画像に設定、LCP要素には不適用 |

### ステップ7: 内部リンク戦略

- 40〜44本の内部リンクを受けるページはクリック数が4倍（45本超で逓減）
- 本文中のコンテキストリンクが最も効果的
- アンカーテキストはリンク先の内容を明確に記述
- トピッククラスターモデル: ピラーページとクラスターページを双方向リンク
- 孤立ページ（オーファンページ）の排除
- リンク切れの定期的な修正

### ステップ8: 構造化データの実装

- JSON-LD形式で実装（Google公式推奨）
- ページの主内容と一致し、ユーザーに可視な情報のみマークアップ
- 主要スキーマ: Article, Product, FAQPage, HowTo, LocalBusiness, BreadcrumbList
- リッチリザルト獲得によりCTRが約30%向上
- 構造化データによりAIの情報精度が16%→54%に向上するデータあり

## 注意事項

- 「最適なキーワード密度」は存在しない。不自然な詰め込みは厳禁
- AI生成コンテンツはGoogleが一律排除しないが、人間による編集・事実確認は不可欠
- コンテンツの定期更新で「鮮度」シグナルを維持する
- Googleはタイトルを書き換えることがあるため、H1との整合性も重要
