# デザインレビュー

UI/UXデザインを多角的に評価し、構造化されたフィードバックを提供します。

## レビュー手順

### 1. ドメインの特定

レビュー対象のドメインを特定し、該当する専門チェックリストを適用します。

| ドメイン | 説明 | 追加チェック項目 |
|---------|------|----------------|
| **Web（一般）** | コーポレート、SaaS、LP、ブログ等 | コンテナクエリ、流動的タイポグラフィ、SEO構造 |
| **ゲームUI** | ブラウザゲーム、Canvas/WebGL | HUDミニマリズム、HSBカラー、ゲーム色彩心理 |
| **TUI** | ターミナルアプリケーション | サンドイッチレイアウト、キーバインド発見性 |
| **ポートフォリオ** | 個人ブランディング、クリエイティブサイト | Three.js/GSAP適切性、受賞サイトパターン |

### 2. ゲシュタルト6原則の確認

人間の知覚の基礎に基づき、レイアウトの直感性を評価します。

#### 近接の法則（Proximity）
- [ ] 関連する要素が物理的に近くにグループ化されているか
- [ ] スペーシングがトークン化されたシステムで管理されているか
- [ ] レスポンシブ再配置時も関連性が維持されるか

#### 類同の法則（Similarity）
- [ ] 同じ機能を持つ要素が一貫した色・形・サイズを持つか
- [ ] デザインシステムを通じて視覚的一貫性が保たれているか
- [ ] ユーザーが直感的に操作規則を学習できるか

#### 閉合の法則（Closure）
- [ ] 最小限の視覚要素で情報が伝達されているか
- [ ] 不必要な境界線やフレームが排除されているか
- [ ] 余白（ホワイトスペース）が効果的に活用されているか

#### 連続の法則（Continuity）
- [ ] ユーザーの視線が論理的な順序で誘導されているか
- [ ] マルチステップのフローが滑らかに進行するか
- [ ] カルーセルやリスト要素が自然な流れを持つか

#### 図と地の法則（Figure-Ground）
- [ ] 主要なCTAが背景から明確に浮き立っているか
- [ ] ダークモードでもZ軸のレイヤリングが適切か
- [ ] コントラストで注意が最重要アクションに焦点化されているか

#### 共通運命の法則（Common Fate）
- [ ] 連動して動く要素群が情報単位として認識されるか
- [ ] スクロールアニメーションが秩序を持つか
- [ ] グループの動きが意味的に一致しているか

### 3. 認知負荷の評価

- [ ] 1画面1目的の原則に従っているか
- [ ] 選択肢が5〜7個以内に収まっているか（ミラーの法則）
- [ ] 複雑なタスクが段階的なステップに分割されているか
- [ ] 情報のスキャナビリティ（流し読みしやすさ）が確保されているか
- [ ] 意味のない装飾や過剰なポップアップが排除されているか
- [ ] 0.05秒の第一印象で信頼性が伝わるか

### 4. 感情的デザインの3レベル

ドナルド・ノーマンの感情的デザイン理論に基づく評価です。

#### 本能的レベル（Visceral）
- [ ] 第一印象が魅力的か（0.05秒テスト）
- [ ] 色彩・形状が適切な感情を喚起するか
- [ ] ビジュアルの品質がブランドの信頼性を伝えるか

#### 行動的レベル（Behavioral）
- [ ] タスク完了までの操作が効率的か
- [ ] フィードバックが即座かつ明確か
- [ ] エラー回復が容易か

#### 内省的レベル（Reflective）
- [ ] ブランドとの個人的な結びつきが形成されるか
- [ ] 使用後の満足感・達成感があるか
- [ ] 他者に推薦したいと思える体験か

### 5. 配色の評価

#### 60-30-10 ルール
- [ ] ドミナントカラー（60%）: 背景・基調色が統一されているか
- [ ] セカンダリカラー（30%）: パネル・カード等の補助色が調和しているか
- [ ] アクセントカラー（10%）: CTA・重要要素が目立っているか

#### コントラストとアクセシビリティ
- [ ] テキストのコントラスト比が4.5:1以上（WCAG AA）か
- [ ] 大文字テキストのコントラスト比が3:1以上か
- [ ] 色だけに依存しない情報伝達か（色覚多様性への配慮）

#### ダークモード
- [ ] ダークモードが提供されているか（91%のユーザーが好む）
- [ ] 単なる白黒反転でなく、深度のある表現か
- [ ] マイクロコントラストが適切に調整されているか

#### P3色域の活用（2026年トレンド）
- [ ] 最新ディスプレイのP3色域を活用しているか
- [ ] sRGBへのフォールバックが適切か

### 6. タイポグラフィの評価

- [ ] バリアブルフォントが活用されているか
- [ ] `clamp()` による流動的タイポグラフィが実装されているか
- [ ] 見出し・本文・キャプションの階層が明確か
- [ ] 行間・字間が読みやすさを最適化しているか
- [ ] 日本語フォントの選定が適切か（Noto Sans JP等）
- [ ] コードブロックにはモノスペースフォントが使用されているか

### 7. アクセシビリティ（WCAG準拠）

- [ ] キーボードのみで完全にナビゲーション可能か
- [ ] セマンティックHTMLが適切に使用されているか
- [ ] スクリーンリーダーでコンテンツ構造が正しく解釈されるか
- [ ] 画像にalt属性が設定されているか
- [ ] フォーカスインジケーターが視認可能か
- [ ] 認知アクセシビリティへの配慮があるか（ADHD、ディスレクシア等）
- [ ] 減モーション（`prefers-reduced-motion`）対応がされているか

### 8. レスポンシブ設計

- [ ] モバイルファーストで設計されているか
- [ ] コンテナクエリが活用されているか
- [ ] タッチターゲットが44x44px以上か
- [ ] ブレイクポイントで情報の優先順位が適切に変化するか

## ドメイン別追加チェック

### ゲームUI固有のチェック項目

#### HUDミニマリズム
- [ ] HUD要素が最小限に抑えられ、ゲーム世界が主役か
- [ ] プレイヤーの30%以上がUI不備で離脱する点を考慮しているか
- [ ] すべてのUI要素が即座に理解可能か

#### HSBカラーシステム
- [ ] 1つのベースカラーからHSBで彩度・明度を調整しているか
- [ ] hover/active/disabled状態が自然に生成されているか
- [ ] 暗い背景に鮮やかなアクセントで目の疲労を軽減しているか

#### ゲーム色彩心理
- [ ] **赤**: 緊急・危険（ダメージ表示、リトライボタン）に使用
- [ ] **青**: 信頼・情報（ナビゲーション、ツールチップ）に使用
- [ ] **緑**: 安全・報酬（ヘルス回復、正のフィードバック）に使用
- [ ] **金/黄**: エネルギー・実績に使用

#### ゲームUI技術
- [ ] CSSカスタムプロパティによるテーマ切替が可能か
- [ ] コンテナクエリでゲームUIコンポーネントがモジュール化されているか
- [ ] ピクセルアートに `image-rendering: pixelated` が適用されているか
- [ ] Canvas のレスポンシブ対応は固定内部解像度+CSSスケーリングか

### TUI固有のチェック項目

#### サンドイッチレイアウト
- [ ] 「上部固定 + 中央スクロール + 下部固定」の三層構造か
- [ ] ヘッダーにゲーム状態（スコア、レベル、モード）を常時表示しているか
- [ ] フッターに利用可能なキーバインドを常時表示しているか
- [ ] 中央領域のみがスクロールするか

#### キーバインドの発見性
- [ ] nanoスタイルのキーバインド表示（`^G Help  ^O Write`）があるか
- [ ] 複数メッセージ時に `--More--` パターンで情報消失を防いでいるか
- [ ] 最小ターミナルサイズ 80x24 を考慮しているか

#### TUI技術
- [ ] スプリットペインが状況に応じて使い分けられているか
- [ ] ターミナルサイズが小さすぎる場合のフレンドリーなメッセージがあるか
- [ ] 色の使用がターミナルのカラーパレット制限を考慮しているか

### ポートフォリオ固有のチェック項目

#### Three.js/GSAP適切性
- [ ] 3D要素が単なる装飾でなく機能的役割を持つか
- [ ] ロード時間が2.5秒以下を維持しているか
- [ ] WebGLフォールバックが適切に処理されているか
- [ ] GSAP ScrollTrigger + Lenis の組み合わせが適切か

#### ポートフォリオパターン
- [ ] 「サイト自体がスキルの証明」となる設計か
- [ ] Bentoグリッドでスキル・プロジェクト・実績を整理しているか
- [ ] 「Lab」セクションで実験的プロジェクトを公開しているか
- [ ] 受賞歴やバージョニングの効果的な表示があるか

#### ビジュアルトレンド（2025-2026）
- [ ] グラスモーフィズム（Liquid Glass）の適切な活用か
- [ ] スクロールテリングでキャリアストーリーを効果的に語っているか
- [ ] ライト/ダークのトグル機能が実装されているか
