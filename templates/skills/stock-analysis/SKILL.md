# 銘柄分析スキル

> 個人利用の自己責任ツールです。最終的な投資判断は自身で行ってください。

---

## 1. ファンダメンタルズ分析

### 1.1 収益性・企業価値の測定指標

企業の価値を定量的に評価するための主要指標です。単独ではなく複合的に分析することで意味を持ちます。

| 指標 | 算出方法 | 意味と実践的解釈 |
|------|----------|------------------|
| **EPS**（1株当たり純利益） | 当期純利益 / 発行済株式数 | 収益力の最も基本的な指標。時系列での増減トレンドを分析する |
| **PER**（株価収益率） | 株価 / EPS | 株価の割安・割高を判断。同業他社との相対比較が必須 |
| **BPS**（1株当たり純資産） | 純資産 / 発行済株式数 | 企業の安定性・下値不安の測定。時系列で純資産の蓄積を評価 |
| **配当利回り** | 年間配当金 / 株価 × 100 | 投資金額に対する年間リターン。株価下落時の下値支持の役割 |
| **売上高伸び率** | (当期売上 - 前期売上) / 前期売上 × 100 | 成長性の先行指標。10%以上はグロース株の可能性 |
| **総資本増加率** | (当期総資本 - 前期総資本) / 前期総資本 × 100 | 企業規模の拡大・縮小トレンドの把握 |

### 1.2 追加で確認すべき指標

- **ROIC**（投下資本利益率）：資本の効率的な投下を評価
- **フリーキャッシュフロー**：実際の現金創出力
- **負債比率・流動比率**：財務安全性の評価
- **配当性向**：利益のうちどれだけ株主還元に回しているか

### 1.3 グロース投資 vs バリュー投資

| 観点 | グロース投資 | バリュー投資 |
|------|-------------|-------------|
| 根拠 | 将来の成長持続性・再投資効率 | 価格 < 企業価値（ミスプライス） |
| 重視指標 | 売上成長率、ROIC、競争優位性 | PBR、PER、FCF、資産価値 |
| 時間軸 | 月〜年 | 月〜年 |
| 主なリスク | 期待剥落による急落 | 価値の罠（構造的悪化の見誤り） |
| 配当 | 少ない傾向（再投資優先） | 相対的に高い傾向 |

### 1.4 業界分析フレームワーク

ポーターのファイブフォース分析で収益性の構造を整理します：

1. **既存競合の脅威**：競争の激しさ、差別化の程度
2. **新規参入の脅威**：参入障壁の高さ
3. **代替品の脅威**：代替製品・サービスの存在
4. **買い手の交渉力**：顧客の価格交渉力
5. **売り手の交渉力**：サプライヤーの影響力

### 1.5 決算の読み方（一般手順）

1. **期末前**：需要、価格、コスト、為替、投資計画の前提をメモ化
2. **決算短信**：前年差だけでなく「予想との差」と「来期見通しの根拠」を確認
3. **有価証券報告書**：セグメント情報、リスク情報、設備投資・研究開発、ガバナンスを含めて仮説更新
4. **分解の4点**：
   - 既に織り込まれていた期待
   - ガイダンスの前提
   - 一時要因（為替、原材料、特別損益）
   - 資本配分（投資・還元）

**一次情報の優先順位**：法定開示（EDINET） → 適時開示（TDnet） → 決算説明資料・IR → 報道 → SNS

## 2. テクニカル分析

### 2.1 ローソク足の基本

- **陽線**（始値 < 終値）：買い手優勢の期間
- **陰線**（始値 > 終値）：売り手優勢の期間
- **上ヒゲ**：高値まで到達後に押し戻された痕跡（売り圧力の存在）
- **下ヒゲ**：安値まで下落後に買い戻された痕跡（買い意欲の強さ）
- **長い下ヒゲの陽線**：セリング・クライマックスからの回復を示唆

### 2.2 トレンドラインとサポート/レジスタンス

- **サポートライン（下値支持線）**：安値同士を結んだ右肩上がりの線。割安感から買いが入る心理的防衛線
- **レジスタンスライン（上値抵抗線）**：高値同士を結んだ線。売り圧力が集中する水準
- **ブレイクアウト**：サポートやレジスタンスを明確に突破した場面。出来高増加で信頼度が上がる
- **ブレイクダウン**：サポート割れ。パニック売りの引き金になり得る

### 2.3 移動平均線

- **短期**（5日・25日）：直近の需給を反映
- **中期**（75日）：中期トレンドの方向性
- **長期**（200日）：大局的なトレンド判断
- **ゴールデンクロス**：短期が長期を上抜け（上昇シグナル）
- **デッドクロス**：短期が長期を下抜け（下降シグナル）

### 2.4 主要指標の役割整理

| 系統 | 例 | 用途 | 典型的な誤用 |
|------|-----|------|-------------|
| トレンド系 | 移動平均、トレンドライン | 順張りの方向付け | レンジ相場で連敗 |
| オシレーター | RSI、MACD | 過熱・反転の補助判断 | 閾値の盲信 |
| ボラティリティ | ATR | ストップ幅・サイズ調整 | 低ボラ時の過大レバレッジ |
| 出来高 | 出来高増減、VWAP | ブレイクの信頼度評価 | 薄商いの軽視 |

### 2.5 マルチタイムフレーム分析

1. **上位足（週足）**：環境認識（大局のトレンド方向）
2. **日足**：シグナルの確認
3. **短い足**：エントリーの執行タイミング

## 3. リスク管理

### 3.1 損失の数学的非対称性

| 下落率 | 元に戻すのに必要な上昇率 |
|--------|--------------------------|
| 10% | 11.1% |
| 20% | 25.0% |
| 30% | 42.9% |
| 50% | **100.0%** |
| 70% | 233.3% |

**核心**：大きな損失は回復が困難。損失の限定が最重要課題。

### 3.2 ポジションサイジングルール

- **1回の最大損失**：総資金の **2%** 以内に制限する
- **計算例**：資金100万円、損切り幅5%の場合
  - 最大損失額 = 100万 × 2% = 2万円
  - 最大投入額 = 2万 / 5% = 40万円
- **ボラティリティ調整**：ATR等でストップ幅を変え、リスク量を一定化

### 3.3 損切り（ストップ）の種類

- **価格基準**：サポートライン割れ、移動平均割れなどの節目
- **時間基準**：想定期間内に目標に到達しない場合
- **ボラティリティ基準**：ATRの倍数で設定
- **重要**：損切りは事前に設定し、機械的に実行する（保有効果の克服）

### 3.4 分散の原則

- 銘柄数を増やすだけでなく、**相関の低い資産を組み合わせる**ことが本質
- 資産クラスの分散：株式、債券、REIT、金など
- 地域の分散：国内、先進国、新興国
- セクターの分散：同業種への集中を避ける

### 3.5 レバレッジの注意

- レバレッジは「利益の拡大手段」ではなく「破滅確率を増やす手段」でもある
- 信用取引では手元資金以上の損失や追証が発生し得る
- 制度・コスト・追証条件を理解してから利用する

## 4. 心理バイアスチェック

### 4.1 損失回避バイアス

- **症状**：利益は早く確定し、損失は先送りする（ディスポジション効果）
- **対策**：事前にストップ設定。損益ではなくルールで売却判断する
- **確認質問**：「この銘柄を今持っていなかったとして、この価格で新規に買うか？」

### 4.2 確率荷重関数の歪み

- **症状**：低確率イベントを過大評価（宝くじ株への期待）、高確率イベントを過小評価
- **対策**：期待値を数値で計算する習慣をつける
- **確認質問**：「この投資の期待値を数字で説明できるか？」

### 4.3 参照点依存性（アンカリング）

- **症状**：買値を基準に判断し、現在の企業価値を無視する
- **対策**：買値を忘れ、現在の価値で判断する
- **確認質問**：「買値ではなく、現在の企業価値に基づいて判断しているか？」

### 4.4 フレーミング効果

- **症状**：情報の提示方法（成功率98% vs 失敗率2%）で判断が変わる
- **対策**：成功・失敗の両面から数字を確認する
- **確認質問**：「この情報を逆の表現にした場合、同じ判断をするか？」

### 4.5 過信バイアス

- **症状**：取引回数が増加し、手数料・ミスが増える
- **対策**：売買回数の上限設定、検証なしの新手法禁止
- **確認質問**：「この判断にデータの裏付けはあるか？感覚だけで動いていないか？」

### 4.6 確証バイアス

- **症状**：都合の良い情報だけ集める
- **対策**：反証質問をテンプレ化する（「この仮説が間違う条件は？」）
- **確認質問**：「反対意見を意識的に探したか？」

```

============================================

【基本情報】
- 銘柄名：
- コード：
- 業種：
- 分析日：
- 分析の目的（グロース / バリュー / 配当 / 学習）：

【ファンダメンタルズ】
- EPS（直近3期の推移）：
- PER（同業他社比較）：
- BPS（直近3期の推移）：
- 配当利回り / 配当性向：
- 売上高伸び率（直近3期）：
- ROIC / ROE：
- フリーキャッシュフロー：
- 財務安全性（負債比率、流動比率）：
- 業界の競争環境（ファイブフォース要約）：
- 情報源（EDINET / TDnet / IR資料等）：

【テクニカル】
- 現在のトレンド（上位足）：上昇 / レンジ / 下降
- 移動平均線の位置関係：
- サポート / レジスタンス水準：
- 出来高の傾向：
- エントリー条件：
- 損切り条件：

【リスク評価】
- 1回の最大損失額（総資金の2%以内か）：
- ポジションサイズ計算：
- 分散状況（ポートフォリオ内の比率）：
- 想定リスクシナリオ：

【心理バイアスチェック】
□ 損失回避：事前にストップを設定したか
□ アンカリング：買値ではなく現在価値で判断しているか
□ フレーミング：成功・失敗の両面を確認したか
□ 過信：データの裏付けはあるか

【総合判断】
- 投資仮説（何が起きれば価値が上がる/下がるか）：
- 仮説が崩れる条件：
- 判断：買い / 様子見 / 見送り（理由）
============================================
```

## 注意事項

- 「理論を信じる」より「理論の示す失敗パターンを避ける」方が再現性が高い
- 税務は個別事情で変わるため、制度の一般論を一次資料で確認すること
- 効率的市場仮説の示唆：公知情報だけで恒常的に超過収益を得るのは容易ではない
- 分析結果は判断材料の一つであり、最終判断は自身で行うこと
