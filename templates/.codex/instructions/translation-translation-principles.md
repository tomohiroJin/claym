# 英日翻訳の原則

> 翻訳プロジェクト作業時に常時適用される原則・チェックリスト

## 基本方針

**動的等価**（ユージン・ナイダ）: 日本語の読者が受ける印象が、英語の読者が受ける印象とほぼ同じになる翻訳を目指す。
**柴田元幸**: 「忠実に、しかしスムーズな日本語に」
**村上春樹**: 「すべては文体だ」「ビートとうねりがないと、文章がうまく呼吸しない」

## 英日翻訳の7つの鉄則

1. **主語を積極的に省略する** — 日本語では動作主が変わらなければ省略が自然。「彼女は」の多用は翻訳臭の元凶
2. **無生物主語を変換する** — "This book gives you..." → 「この本を読めば…が得られる」
3. **受動態→能動態** — 日本語では能動態が自然な場合が多い。「～される」の多用を避ける
4. **冠詞は基本訳出しない** — a/the は文脈に応じて「ある～」「その～」とするか、多くは訳出不要
5. **長文は分割する** — 英語の関係代名詞・接続詞による長文は日本語の複数文に。主部と述部を近く保つ
6. **英語の語順に引きずられない** — 日本語として自然な語順に再構成する
7. **オノマトペを活用する** — 英語の形容詞/副詞を日本語のオノマトペに変換して生き生きとした表現にする

## 翻訳臭さチェックリスト

翻訳後に以下を確認する:

- [ ] 「彼」「彼女」「それ」が1段落に2回以上出現していないか
- [ ] 無生物が意志を持って行動する文がないか
- [ ] 「～することができる」等の冗長表現がないか
- [ ] 主部と述部が離れすぎている文がないか
- [ ] 「～において」「～に関して」等の硬い表現が多用されていないか
- [ ] 原文にない説明が勝手に追加されていないか
- [ ] 訳抜け（原文にあるのに訳出されていない箇所）がないか

## 定型表現・口癖の一貫性（最重要）

- キャラクターの口癖・定型表現は **初出時に訳語を確定し、translation-notes.md に記録**する
- 以降の全出現で **完全に同一の訳語** を使う（語尾の微調整も不可）
- 例: "Come on!" → 「さあ行くぜ！」と決めたら、他キャラの引用時も「さあ行くぜ！」
- 章をまたぐ反復表現・対句・エコーも同様に統一する

## 視覚表現・書式の扱い

### イタリック（`<i>` タグ）
- 英語のイタリック強調は日本語では **傍点（圏点）** に変換する
- XHTML の場合: `<i>word</i>` → `<em class="emphasis">文字</em>` + CSS で傍点指定
- または二重括弧やカギ括弧で代替: 「『ほんとうに』そう思った」
- **何を強調しているかが日本語でも明確に伝わること**を確認する

### 視覚詩・具象詩（Concrete Poem）
- 文字の視覚的配置が意味を持つ詩は、**日本語でも視覚レイアウトを再現**する
- 文字数・行の長さが異なるため、日本語の文字幅に合わせてインデントを再調整する
- HTML/CSS の `<pre>` や `style` 属性を活用してレイアウトを制御する
- 完全な再現が不可能な場合は、最善の近似を試み、訳注で補足する

### 挿絵・画像
- `<img>` タグは **絶対に削除しない**。属性（src, alt, class, style）もすべて保持
- `alt` 属性のテキストは日本語に翻訳する
- 挿絵の前後のテキストが絵の内容を参照している場合、その対応関係を崩さない

## EPUB 翻訳の固有ルール

- XHTML 構造（タグ・属性・id・class）を **完全に保持** する
- `lang="en"` → `lang="ja"` に変更する
- `<title>` の内容を日本語にする
- CSS ファイルは原則変更しない（傍点用の追加 CSS は例外として許可）
- メタデータ（content.opf）の `dc:title`, `dc:language` を日本語化する
- TOC（toc.xhtml, toc.ncx）の章タイトルを日本語化する
- Project Gutenberg のライセンスページ（最終章）はそのまま保持する

## 文学翻訳の追加原則

### キャラクターの口調
- 一人称（私/僕/俺/あたし等）は characters.yaml で定義し、全章で一貫させる
- 語尾パターンも同様に定義・維持する
- ステレオタイプ的な役割語（「～だわ」で女性を表す等）は避ける

### 言葉遊び・文化的参照
- 直訳不可能な言葉遊びは、日本語で等価の効果を持つ表現を創作する
- それも難しい場合は translation-notes.md に判断を記録し、代替策を採る
- 文化的参照は安易に日本の等価物に置き換えず、原文の異質さを保つ（異化寄り）

### 品質の最終基準
- **音読テスト**: 声に出して読み、リズムや流れに違和感がないか
- **透明性テスト**: 翻訳であることを知らない人が読んで違和感がないか
- **忠実性テスト**: 原文の情報が欠落・改変されていないか
