# UI/UXデザイン原則チェックリスト

デザインの品質を担保するための簡潔なチェックリストです。

## ゲシュタルト6原則

- [ ] **近接**: 関連要素が物理的に近くにグループ化されている
- [ ] **類同**: 同機能の要素が一貫した色・形・サイズを持つ
- [ ] **閉合**: 最小限の視覚要素で情報伝達、余白を活用
- [ ] **連続**: 視線が論理的な順序で誘導される
- [ ] **図と地**: 主要CTAが背景から明確に浮き立つ
- [ ] **共通運命**: 連動して動く要素が情報単位として認識される

## 認知負荷

- [ ] 1画面1目的に絞る
- [ ] 選択肢は最大5〜7個（ミラーの法則）
- [ ] 複雑なタスクは段階的ステップに分割
- [ ] スキャナビリティ（流し読みしやすさ）を確保
- [ ] 過剰な装飾・ポップアップを排除（Calm UI）
- [ ] 0.05秒の第一印象で信頼性を伝える

## 配色

- [ ] **60%** ドミナント（背景・基調色）
- [ ] **30%** セカンダリ（パネル・カード）
- [ ] **10%** アクセント（CTA・重要要素）
- [ ] テキストコントラスト比 4.5:1 以上（WCAG AA）
- [ ] 色だけに依存しない情報伝達
- [ ] ダークモード提供（必須）

## マイクロアニメーション

- [ ] 機能的な瞬間のみに限定（装飾目的は排除）
- [ ] 300ms 以内の持続時間
- [ ] システム状態のフィードバックに使用
- [ ] `prefers-reduced-motion` でオプトアウト可能

## ゲームUI固有

- [ ] HUD要素を最小限に（ゲーム世界が主役）
- [ ] HSBカラーで状態バリエーションを統一生成
- [ ] 赤=危険、青=情報、緑=回復、金=実績
- [ ] 暗い背景+鮮やかなアクセントで目の疲労を軽減
- [ ] `image-rendering: pixelated`（ピクセルアート時）

## TUI固有

- [ ] サンドイッチレイアウト（上固定+中スクロール+下固定）
- [ ] ヘッダーにゲーム状態を常時表示
- [ ] フッターにキーバインドを常時表示（nanoパターン）
- [ ] `--More--` パターンで情報消失を防止
- [ ] 最小サイズ 80x24 を考慮
- [ ] スクロールは中央領域のみに限定

## ポートフォリオ固有

- [ ] 3D要素は装飾でなく機能的役割を持つ
- [ ] ロード時間 2.5秒以下を維持
- [ ] Bentoグリッドでスキル・実績を整理
- [ ] ライト/ダークトグル実装
- [ ] 「サイト自体がスキルの証明」となる設計
