# SEOベストプラクティス チェックリスト

SEO施策の判断基準を3段階で整理したものです。
ソース: Googleスパムポリシー、モバイルファーストインデックス、Core Web Vitals公式文書

---

## 絶対禁止（スパムポリシー違反 -- 手動対策/除外リスク）

1. **キーワード乱用**: タイトル・本文・フッターでの不自然な語句反復・地域名羅列
2. **クローキング**: UA/IPでGooglebotと人間に異なるコンテンツを提供
3. **隠しテキスト/リンク**: opacity:0、画面外配置、白文字等による隠蔽
4. **リンクスパム**: 有償リンク購入、PBN、自動生成リンク、低品質ディレクトリ投下
5. **スニーキーリダイレクト**: 検索経由やモバイルだけ別URLへ不正転送
6. **ドアウェイページ乱用**: 地域名・条件だけ変えた類似LP量産
7. **スケールしたコンテンツ乱用**: 付加価値なしのAI大量生成、スクレイピング転載

> 発見時の対応: 原因除去 → Search Console で再審査リクエスト（回復まで2〜8週）

---

## 必須対応（インデックス可能性 -- 露出効率の阻害要因）

1. **重複コンテンツ解消**: canonical/301で代表URL統一、サイトマップを代表URLに限定
2. **ページネーション整備**: 深部ページをa hrefで辿れるようにする、フィルタURLのインデックス制御
3. **hreflang正確性**: ISO準拠コード使用、全言語で同一セットの相互参照、壊れURL修正
4. **JavaScript対応**: 主要コンテンツ/リンクをSSR/プリレンダで提供、リンクはa hrefで記述
5. **モバイル同等性**: モバイル版にPC版と同等の主要コンテンツ・構造化データ・メタを確保
6. **薄いコンテンツ対策**: 付加価値のないページを統合・削除・noindex、一次情報を追加

> 対応順序: URL在庫整理 → 正規化 → レンダリング/モバイル整備 → コンテンツ改善

---

## 推奨（UX/速度/モニタリング -- CTR/CVR改善に寄与）

1. **Core Web Vitals達成**: LCP≤2.5秒、INP≤200ms、CLS≤0.1（まず最遅クラスタを改善）
2. **構造化データ適正化**: JSON-LDで可視要素のみマークアップ、虚偽/無関係スキーマ禁止
3. **広告/インタースティシャル改善**: ファーストビューに本文確保、全画面ポップアップ排除
4. **定期監視の定着**: Search Console手動対策（毎週）、CWV（月次）、被リンク監査（月次）
5. **AI Overview対応**: E-E-A-T強化、40〜60語の簡潔回答段落、検証可能なデータポイント

> 改善の費用対効果: スパム是正 > 正規化/インデックス > レンダリング/モバイル > 速度/UX
